# GoDaZ – Personal Portfolio Website

This is a responsive personal portfolio website built using **HTML, CSS, and JavaScript**.  
It showcases my skills, services, and professional profile with a modern UI and smooth interactions.

## Features
- Responsive design for desktop and mobile devices
- Fixed navigation bar with mobile hamburger menu
- Typing text animation using CSS keyframes
- Social media icons with hover effects
- Clean, modern UI with smooth transitions

## Technologies Used
- HTML5
- CSS3 (Flexbox, Media Queries, Animations)
- JavaScript (DOM manipulation)
- Font Awesome
- Google Fonts (Poppins)
